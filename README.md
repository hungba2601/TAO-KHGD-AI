# KHGD AI VIP V4.0 - Ứng dụng AI Xây Dựng Kế Hoạch Giáo Dục Tự Động

Ứng dụng web Next.js 16 + React 19 + Tailwind CSS v4 hỗ trợ giáo viên Việt Nam tự động hóa toàn bộ quy trình xây dựng Kế hoạch Giáo dục Nhà trường & Kế hoạch Dạy học theo chuẩn chỉ đạo của Bộ Giáo dục và Đào tạo.

## Tính năng Nổi bật
- **Chuẩn hóa 100% Căn cứ Pháp lý**:
  * Công văn 5512/BGDĐT-GDTrH (THCS & THPT).
  * Công văn 2345/BGDĐT-GDTH (Tiểu học).
  * Thông tư 32/2018/TT-BGDĐT (Chương trình GDPT 2018).
  * Thông tư 37/38/39/TT-BGDĐT (Thiết bị dạy học tối thiểu).
  * Công văn 3456/BGDĐT-CNTT (Chuyển đổi số, giáo dục STEM và tiếp cận AI).
- **Trọn bộ 3 Phụ lục chuẩn**:
  * **Phụ lục 1**: Phân phối chương trình 35 tuần, Danh mục Thiết bị dạy học, Phòng học bộ môn, Kế hoạch Kiểm tra Đánh giá Định kỳ (GK1, CK1, GK2, CK2), Nhiệm vụ chuyên môn khác.
  * **Phụ lục 2**: Kế hoạch Tổ chức Hoạt động Giáo dục, Ngày hội trải nghiệm số và Chuyên đề Dự án STEM liên môn.
  * **Phụ lục 3**: Kế hoạch Giáo dục Cá nhân Giáo viên, Kế hoạch tự bồi dưỡng và nâng cao năng lực ứng dụng AI.
- **Tích hợp Google Gemini AI**:
  * Đa mô hình thông minh (`gemini-2.5-flash`, `gemini-2.0-flash`, `gemini-1.5-flash`).
  * Quy trình tạo 5 giai đoạn với thanh tiến trình % và nhật ký terminal real-time.
  * Tự động dự phòng dữ liệu mẫu chuẩn khi ngoại tuyến hoặc không có API key.
- **Xuất file Word .docx Chuẩn Quốc gia**:
  * Font chữ Times New Roman, cỡ 12-14pt, lề chuẩn văn bản hành chính.
  * Khung bảng viền đơn nét rõ ràng, phần ký duyệt trang trọng.

## Cài đặt & Chạy Dự án

```bash
# Cài đặt thư viện
npm install

# Chạy môi trường phát triển (Dev)
npm run dev

# Kiểm tra kiểu TypeScript
npm run typecheck

# Build sản phẩm (Production)
npm run build
```
